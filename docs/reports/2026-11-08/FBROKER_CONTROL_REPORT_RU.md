# Контрольный FBroker — DCI_Hack_kiker

8 ноября 2026 года реально обработаны **10/10** новых чатов FBroker. Итоговый файл: `results/prod/results.json`, JSON schema 1.0 по приложению организаторов; **80 оценок критериев, 0 ошибок обработки**. DEV содержит 65 результатов в `results/dev/results.json`. SWAP: 3 записи сохранены отдельно, не оценены и не включены в PROD.

## Модель и процесс

Qwen3:30b Q4_K_M через Ollama 0.40.15 на NVIDIA RTX A6000 48GB в Brev. Режим сдачи `local`: модель развёрнута самостоятельно. Контекст 32768, выход до 8192 токенов, temperature 0, think=false. Digest проверен до первого запроса и сохранён в audit JSON.

Все 10 диалогов прошли единый протокол `cqa-1.3-adaptive-review+fbroker-control-v1-uniform-proof-identity` с исходным основным чек-листом. Исходники получены из предоставленного ответа API FBroker. Модель не получала Ground Truth, ручных подмен оценок не было. Проверены хеши входов, чек-листа, кода и конфигурации; итоговые оценки сопоставлены с фактическими ответами в журнале запросов. Код использованного ядра соответствует коммиту `86e586c6754c10dcedf37521a5c80d093a73f665`; последующие изменения main не меняют происхождение этого прогона. Воспроизведение описано в `scripts/control_runner/README.md`.

Прогон: **11:22:54–11:35:51 по Алматы**, 12.95 минуты. Среднее время запросов на диалог — **77.67 секунды**, без подготовки GPU. Всего 19 запросов, 8 повторных проверок и 1 запрос на исправление. Вход: 198257 токенов; выход: 89503 токена.

## Проверки и ограничения

Независимо проверены все 10 ID, восемь критериев для каждого чата, типы значений, допустимые N/A, цитаты и нумерация по полному исходному транскрипту. Итоги пересчитаны по применимым весам, `critical_flag` передаётся отдельно. Все результаты прошли экспорт без ошибок. На сайте теперь 75 оценённых диалогов; прежняя история сохранена, перед импортом создана резервная копия SQLite.

Один первоначальный ответ содержал неверный временной порядок доказательств идентификации; валидатор отклонил его, модель выполнила исправление. В двух чатах (`p2-ru-003`, `p2-ru-004`) первый и повторный проходы разошлись по отдельным критериям. Эти расхождения сохранены в истории, поэтому уверенность в семантической точности ограничена. Схема и корректность цитат проверены; **точность относительно Ground Truth не измерена**.

Три аренды суммарно: около **$1.8225** по времени. Условный расчёт с округлением каждой аренды до целых часов — **$2.568**; оба расчёта ниже общего лимита $5. Финальный биллинг Brev не проверен, это оценка по тарифам и времени, а не банковское списание. Временные файлы с ключом удалены после подтверждения удаления GPU.
