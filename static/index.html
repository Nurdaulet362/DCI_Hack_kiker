Загрузите DEV или контрольный набор из API организаторов.

ИЛИ JSON-ФАЙЛ

Формат: conversation_id, language (RU/KZ/EN), channel, transcript [{timestamp, speaker, text}], audio_url. Замена ID обновляет транскрипт, сохраняя историю оценок.

Подключение AI

Откройте локальный .env в папке проекта, заполните настройки провайдера и перезапустите сервер:

AI_PROVIDER=openai_compatible
AI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai
AI_MODEL=gemini-3.8-flash
AI_API_KEY=ваш-ключ
AI_REVIEW=true

Для OpenAI: AI_PROVIDER=openai. Для локальной модели: AI_PROVIDER=ollama, AI_BASE_URL=http://127.0.0.1:11434. Ключ остаётся на сервере. API должен поддерживать JSON Schema.

Точность относительно Ground Truth ещё не измерена. Уверенность модели в результате — её самооценка.
