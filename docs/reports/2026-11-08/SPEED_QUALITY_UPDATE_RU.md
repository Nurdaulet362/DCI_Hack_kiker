# Оптимизация скорости и протокола оценки

8 ноября 2026. Версия cqa-1.3-adaptive-review. Изменения сохраняют прежнюю историю и снимки; новые результаты требуют нового вызова доступного AI.

## Изменения

- Новый режим auto в UI и API; CLI --review-mode auto/full/single. Простые случаи получают один проход, рискованные — независимый второй. Причины и факт реальной перепроверки сохраняются в review_decision; reviewed показывает выполненную операцию.
- Эскалация по звонкам, неопределённостям, низкому confidence, неполным/отрицательным оценкам, грубым флагам, защищённым действиям, новым правилам, возможным переспросам и сомнительному представлению. Сигналы маршрутизации не меняют ответы и не привязаны к ID диалога. Возможны пропуски и лишние перепроверки.
- Для исходного критерия идентификации добавлены protected_action и verified_before_action. Действие подтверждает оператор; клиентские сведения не засчитываются как раскрытие оператором. Проверка после защищённого действия отклоняется. Проверку внутри одной реплики по смыслу определяет модель.
- Уточнено, что вопрос без имени не является представлением; пожелание, «пожалуйста» и вопрос об обратном звонке не заменяют компоненты завершения. Рекомендация не является уточняющим вопросом. Частная услуга не обнуляет автоматически полезный ответ по консультации. Текущие правила и веса не менялись.
- Инструкция просит краткие обоснования и достаточные короткие точные цитаты. JSON входа компактнее. Транскрипты не обрезаются.
- Основной Ollama-адаптер явно передаёт think=false и контекст 32768 по умолчанию. Можно настроить AI_THINK/AI_CONTEXT_WINDOW; память, совместимость и скорость выбранной модели требуют проверки. Ранее основной адаптер не фиксировал эти параметры экспериментального запуска.
- Исправлена согласованность ID и видимой карточки при загрузке, подпись режима. При shutdown сигнал прекращает следующие запросы; текущий сетевой запрос может завершиться. CLI возвращает ошибку при неуспешных оценках пакета. data:null отклоняется как ошибочный импорт.

## Проверка

85 автоматических тестов проходят, включая новые проверки маршрутизации, числа вызовов, идентификации, поздней проверки, совместимости режимов и некорректного импорта. Проверены синтаксис JavaScript и Python. В браузере режим auto выбран по умолчанию; доступны все три варианта, сохранённые 65 оценок доступны. Тесты используют синтетические ответы в изолированной среде и не измеряют понимание текста моделью.

## Ориентир скорости

Первый проход старого запуска: 19,42 секунды в среднем; второй: 18,84. Маршрутизация по сохранённым первым ответам отправила бы на повторную проверку 31 из 65, включая известные проблемные случаи. Если переиспользовать прежние длительности запросов, расчёт даёт 28,59 секунды в среднем вместо 38,25 — примерно на 25% меньше. Это воспроизведение решений маршрутизации на старых данных, НЕ новый AI-бенчмарк. Новые проверки идентификации, длина ответов и окно контекста в этих длительностях не представлены.

Новый платный прогон не запускался; GPU остаются удалёнными. Улучшение точности, новые баллы 65 диалогов и реальное время новой версии не измерены. Часть ошибок может остаться даже после второго прохода. До контрольного этапа нужен небольшой реальный пилот на доступном провайдере, затем независимый Ground Truth. При недоступном AI сайт показывает сохранённые результаты, но новые не придумывает.
